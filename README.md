# 豆包鼠标语音助手

让 Logi Options+ 发出的鼠标快捷键触发豆包输入法语音。程序常驻 Windows 右下角通知区域，关闭设置窗口后继续运行；换键只改豆包和 Logi Options+ 的原有设置。

这是非官方 Windows 工具。当前发布 **v0.2.0-rc.1 源码预览版**，包含托盘管理、后侧键只读检查、Win/Alt 菜单抢焦点路径修复，以及新的深蓝色“鼠标＋声波”图标。

**下载：[v0.2.0-rc.1 Release](https://github.com/lumiai101/doubao-mouse-bridge/releases/tag/v0.2.0-rc.1)**。选择 `doubao-mouse-bridge-v0.2.0-rc.1-source.zip`，安装与运行见下文。下载包需要安装依赖，不包含 EXE、Python 运行环境或安装器。

> 本版通过 74 项离线测试和隔离桌面检查，尚未完成本版实体鼠标语音、真实登录和长期常驻验收。图标出现、按键设置匹配，都不表示麦克风和文字上屏正常。完整边界见 [验证记录](docs/tray-verification.md) 和 [版本说明](docs/releases/v0.2.0-rc.1.md)。

## 能做什么

- 从豆包读取长按和免按快捷键，保存新设置后自动重读，无需改代码或重启。
- 使用豆包自己的本地语音接口启停录音，识别结果由豆包上屏。
- 从系统托盘打开设置、暂停、恢复、重新检查和退出。再次启动时呼出已有窗口。
- 只读检查罗技下方/后侧键绑定，与豆包组合比较，区分左右修饰键；不改上侧键或滚轮设置。
- 对已接管的模拟 Win/Alt 组合，在松开时屏蔽裸修饰键引发系统菜单的路径。
- 透传实体键盘事件。实体长按持续约 0.6 秒且豆包尚未录音时尝试补启动，短按不触发。
- 语音接口在临时子进程中运行。语音错误后停止接受新触发，恢复前提示核对豆包录音状态。

程序不能识别模拟按键来自哪只鼠标。其他宏软件发出的相同组合也可能触发；它不能解决所有系统或应用的快捷键冲突。

## 安装并开始使用

需要 Windows x64、可正常识别文字的豆包输入法、Logi Options+，以及 [uv](https://docs.astral.sh/uv/getting-started/installation/)。当前接口白名单包含豆包 **v0.9.2.7**、**v0.9.3.19**，配置格式为 schemaVersion **12**。每次创建语音子进程时都会检查 `rpc.dll` 的 SHA-256，即文件内容的校验值；不匹配时拒绝调用。不要只替换校验值绕过保护。

1. 从上面的 Release 下载源码 ZIP，解压到固定目录。
2. 双击 `setup.cmd`。脚本在本目录创建 `.venv`，安装固定版本依赖；缺少 Python 3.13 时，uv 按自身设置获取解释器。此步骤需要联网。
3. 双击 `start.cmd`。在右下角通知区域找到“鼠标＋声波”图标，图标可能位于隐藏图标列表中。
4. 点击图标，或右键选择 **打开设置**，核对豆包快捷键及后侧键检查结果。
5. 在豆包 **语音输入 → 长按模式** 中选择无冲突组合，再在 Logi Options+ 给下方/后侧键设置相同组合。左右 Alt、Ctrl 等必须对应；免按模式也须在两边设置一致。
6. 聚焦普通文本框并切换到豆包输入法。长按模式按住说话、松开结束；免按模式按一次开始、再按一次结束。确认录音结束且文字出现。

例如可先测试左 Alt+K，再在双方设置换成左 Alt+J。它们是测试示例，程序没有固定使用这两组键。不要同时运行其他豆包语音桥接程序。

### 已有 Python 时手动安装

推荐 Python 3.13 x64，包含 tkinter。标准 python.org Windows 安装包可提供 tkinter。在源码目录运行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -B -I src\doubao_mouse_bridge.py
```

手动安装需要 pip，`setup.cmd` 使用 uv。依赖为 pynput 1.8.2、six 1.17.0、pystray 0.19.5、Pillow 11.3.0；来源和许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 看懂托盘状态

所有状态保留深蓝鼠标和声波。悬停文字、菜单和设置窗口提供具体原因。

| 图案 | 含义与核对办法 |
|---|---|
| 鼠标＋声波，无角标 | 监听及已读取的侧键检查未发现问题。仍须实体按键确认语音。 |
| 琥珀色小点 | 有待检查项。在设置窗口看快捷键、侧键或故障提示。 |
| 双竖线 | 已暂停。在菜单选择恢复，程序重新读取设置。 |
| 紫色圆环 | 录音状态未确认。先在豆包及系统麦克风提示中确认录音已结束。 |

**重新检查** 只重新读取设置与监听状态，不开启录音，不自动重试失败的语音命令。语音错误后，须确认已在豆包检查并结束录音，才允许恢复。托盘启动失败时，程序显示控制窗口作为入口。

### 检查和更换后侧键

设置窗口显示豆包长按、免按快捷键，以及罗技下方/后侧键已有绑定。程序每 2 秒在后台读取罗技设置，不在按键回调中读数据库，不提供第二套快捷键编辑器。

设备列表来自罗技保存的历史记录，**不证明当前在线**。只有本机设备描述确认后侧键编号时才解析；存在应用专属设置、无法识别型号或两边不一致时提示检查，不猜测当前映射。

窗口提供 **打开豆包**、**豆包输入法设置**、**罗技按键设置**。豆包语音页启动参数已有本机字符串证据，但未实测跳页；罗技按钮打开软件主窗，仍需选择鼠标和后侧键。入口缺失时显示提示。

更换快捷键时，在豆包和 Logi Options+ 保存相同组合，等待窗口更新后再实测。

## 退出、升级和登录启动

点击窗口右上角 **X** 或 **隐藏到托盘** 仅隐藏窗口。要停止适配，在托盘菜单选择 **退出**，或在窗口点击 **退出程序**。

也可在源码目录运行：

```powershell
.venv\Scripts\pythonw.exe -B -I src\doubao_mouse_bridge.py --background
.venv\Scripts\python.exe -B -I src\doubao_mouse_bridge.py --stop
```

第一条后台启动，第二条发送退出请求。退出请求返回不证明进程已结束，也不证明豆包录音已停止。**出现语音错误或异常退出时，检查豆包界面及系统麦克风使用提示，必要时在豆包中手动结束录音。** 程序没有可靠的逐会话身份校验，运行期间避免通过其他入口另开语音。

升级时先从旧窗口或托盘退出，再将新版解压到独立目录并运行 `setup.cmd`、`start.cmd`。0.1.0 不支持 `--stop`，须在旧控制窗退出。重复启动不会自动替换旧实例。

程序不自动添加、改写或删除登录启动项。需要时，可在 Windows 当前用户启动文件夹创建指向 `.venv\Scripts\pythonw.exe` 的快捷方式，参数为 `-B -I "源码完整路径\src\doubao_mouse_bridge.py" --background`。使用实际解压路径，并核对 Logi Options+ 登录后也在运行。

**升级后已有启动快捷方式不会自动更新。** 检查其目标和参数，避免下次登录启动旧目录。本版尚未完成真实登录验证。停用自启动时删除自行创建的快捷方式；卸载前退出程序、确认豆包停止录音，再删除下载目录。uv 共享的解释器和缓存由 uv 管理，不随目录删除。

## 验证与已知限制

本版离线回归为 **74 项通过**，覆盖快捷键、长按兜底、后侧键读取、菜单抑制、故障恢复和主入口。离线测试不录音、不注入全局按键、不安装输入监听。隔离桌面检查使用真实 Tk 窗口与 pystray，但用替身代替语音和输入监听。

在已安装依赖的 Windows 环境中运行：

```powershell
python -X utf8 -B -I -m unittest discover -s tests -p "test_*.py" -v
python -X utf8 -B -I scripts\verify_tray.py
python -X utf8 -B -I scripts\check_release.py
```

`verify_tray.py` 需要可交互的 Windows 桌面。发布检查严格检查文件清单，本地额外工作副本可能让它拒绝通过；Release ZIP 只收录清单中的公开文件。维护者可按 [贡献说明](CONTRIBUTING.md) 生成并复查下载包。

历史版本已在本机完成部分实体语音与换键验证，不能替代本预览版终验。本版尚未完成实体鼠标语音、真实登录、睡眠唤醒、Explorer 重启、高 DPI 和长期运行验收，Windows 11 及其他设备也无本版完整验收。Win/Alt 修复已有隔离回放证据，不能保证所有系统快捷键都无冲突。远端自动检查结果以 PR 的 Checks 页面为准。

## 隐私与接口边界

程序只读 `%APPDATA%\DoubaoIme\conf\config.json`、`%LOCALAPPDATA%\LogiOptionsPlus\settings.db` 和 Logi Options+ 安装目录的设备描述，不上传它们，不记录鼠标序列号或完整数据库。

日志位于 `src\doubao_mouse_bridge.log`，记录状态、快捷键和进程号，不主动记录识别正文或音频。父子进程共用轮转日志，尚无跨进程协调保证；`.log`、`.log.1`、`.log.2` 都可能含本机路径，反馈前须脱敏。

本程序不自建录音或识别服务，没有网络请求、剪贴板或文字注入逻辑。豆包可能联网识别，其数据行为以豆包隐私政策为准。豆包接口不是公开稳定接口，升级可能使工具停用。不要在密码框或敏感输入框中试用。
