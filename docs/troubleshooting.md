# 排查与恢复

## 窗口提示接口版本已变化

本程序校验 `rpc.dll` 哈希。豆包升级后不匹配会拒绝启用。

不要只修改 `ALLOWED_RPC_SHA256` 绕过保护。先验证新版本的导出函数、调用约定、状态语义和完整实体启停，再评估兼容改动。没有这些证据时退出工具，等待兼容修复。

## 没有触发语音

1. 确认适配窗口没有暂停，且显示的设置与豆包当前设置一致。
2. 确认目标输入框正在使用豆包输入法。
3. 核对双方组合、左右Alt或Ctrl是否一致，长按动作是否能保持按下直到松手。
4. 关闭其他语音桥接软件后重新测试。本程序不会关闭其他进程。
5. 先使用普通文本框验证，不在管理员窗口、密码框或系统保留组合上测试。

若仍失败，只提供操作系统、豆包及罗技软件版本、快捷键和发生步骤。不要上传整份豆包配置、完整日志或语音内容。

## 提示已有语音会话

结束豆包当前语音，等待识别完成，再重试。程序在启动前发现非空闲状态会拒绝启动，不会循环重试。

程序没有可靠的逐会话身份校验。适配运行期间不要通过其他入口或工具另开语音，不能保证不影响随后创建的会话。

## 没有识别文字

触发成功不等于麦克风和识别正常。先核对豆包本身的麦克风选择、系统权限和网络状态。本程序不另开识别服务，不能修复豆包本身的识别故障。

## 双击启动后窗口关闭

主要查看错误弹窗和 `src\doubao_mouse_bridge.log`。错误不一定打印到终端，启动脚本也不保证错误后窗口保留。需要手动启动时，在终端运行：

```powershell
.venv\Scripts\python.exe -B -I src\doubao_mouse_bridge.py
```

本版重复启动会请求呼出已有实例窗口，然后退出，不安装第二份监听。旧实例没有显示事件时会提示从原入口查看。重复启动不会自动将旧实例升级。

## 后台运行后找不到窗口

默认启动后设置窗口隐藏，程序留在右下角通知区域。先展开隐藏图标列表，点击“鼠标＋声波”或右键选择 **打开设置**，也可再次运行 `start.cmd` 呼出窗口。关闭设置窗口只是隐藏，托盘失败时程序显示控制窗。

需要退出时，在托盘选择 **退出**，或在源码目录运行：

```powershell
.venv\Scripts\python.exe -B -I src\doubao_mouse_bridge.py --stop
```

该命令只发送请求。没有实例、旧版本不支持停止事件时也会返回，不证明实例已停止。检查日志及相关进程是否退出。后台错误主要记录在 `src\doubao_mouse_bridge.log`，轮转备份也可能包含错误信息。

## 琥珀色点或侧键需检查

打开设置窗口，查看具体原因。罗技列表是历史设备，不是在线设备列表；应用专属设置、未知型号或两边组合不一致都会提示检查。只在豆包和 Logi Options+ 原有界面修改按键，不编辑数据库。保存后等待检查结果更新，再用实体侧键测试。

如果按下后侧键仍弹系统菜单，先核对当前运行路径及启动快捷方式是否指向新版目录。本版修正了已匹配模拟 Win/Alt 释放变成裸键的路径，不保证未匹配组合或所有系统快捷键都被屏蔽。

## 出现取消错误或异常退出

“适配已停用”仅表示不再接受新的触发，不保证豆包录音已停止。检查豆包语音界面及系统麦克风使用提示，必要时在豆包中手动结束录音。确认停止前不要继续谈论敏感内容。

## 停止使用

语音命令等待 25 秒超时后只会终止语音子进程，不保证豆包已停止录音。强制结束进程也不保证清理。确认录音停止前，不再通过其他入口开启语音。

## 升级旧版本

0.1.0 没有停止事件，不能靠新版 `--stop` 退出。在旧控制窗点击 **退出**，确认进程结束后再启动新版。单实例锁会阻止新旧版本同时安装监听。

将新版解压到独立目录，运行 `setup.cmd` 后启动。已有登录快捷方式不会随解压自动更新，检查其目标与参数，避免下次登录又运行旧版。本版不自动修改启动项；回退时退出新版并从原目录启动。

## 撤销适配

1. 在控制窗点击 **退出**，或从后台发送上述退出请求。核对豆包已停止录音。
2. 保留或在双方正常设置中自行更改快捷键。程序不会替你回写设置。
3. 仓库不自动创建启动项。若你自行添加过登录启动快捷方式，在当前用户启动文件夹删除该快捷方式，否则下次登录还会启动。
4. 不再需要源码目录时，确认程序已退出后再删除下载目录。没有本工具安装的驱动或服务需要卸载。

`setup.cmd` 创建的 `.venv` 仅在源码目录内。uv管理的解释器或缓存由uv自身管理，删除源码目录不自动清理这些共享文件。
