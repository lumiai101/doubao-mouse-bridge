# v0.2.0-rc.1 · 托盘源码预览版

本版将原有适配工具改为 Windows 通知区域常驻，并加入后侧键检查和新的“鼠标＋声波”图标。这是需要安装依赖的源码预览版，不包含 EXE、安装器或 Python 运行环境。

**尚未完成本版实体鼠标语音、真实登录和长期常驻验收。** 适合愿意自行验证并保留旧目录的使用者。图标出现或按键设置匹配不证明实际录音与文字上屏正常。

## 本版变化

- 默认进入系统托盘。菜单可打开设置、暂停、恢复、重新检查和退出；关闭设置窗口只隐藏，再次启动呼出已有窗口。托盘失败时显示控制窗。
- 每 2 秒只读比较罗技下方/后侧键和豆包原有快捷键。未知型号、应用专属设置或不匹配会提示检查；不改上侧键、滚轮或双方设置。
- 修正已接管的模拟 Win/Alt 组合在释放时被系统视为裸修饰键、进而弹出菜单的路径。实体键盘与未匹配组合仍透传。
- 语音错误后停止接受新触发。恢复前要求确认已在豆包检查并结束录音，“重新检查”不启动录音。
- 用深蓝鼠标和声波替换整幅感叹号。琥珀色点表示待检查，双竖线表示暂停，紫色环表示录音状态未确认；具体原因见悬停提示和设置窗口。
- 保留豆包 v0.9.2.7、v0.9.3.19 双版本接口白名单与原有长按、免按行为。

## 下载并运行

1. 下载附件 `doubao-mouse-bridge-v0.2.0-rc.1-source.zip`，解压到固定目录。
2. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，确认豆包输入法和 Logi Options+ 本身可以正常使用。
3. 双击 `setup.cmd`，安装 Python 3.13 与固定版本依赖。需要联网。
4. 双击 `start.cmd`，在右下角通知区域打开“鼠标＋声波”，核对双方快捷键，再在普通文本框中实测。

推荐 Windows x64、Python 3.13，含 tkinter。依赖为 pynput 1.8.2、six 1.17.0、pystray 0.19.5、Pillow 11.3.0。

附件 `.sha256` 是源码 ZIP 的校验值。可在 PowerShell 中运行 `Get-FileHash .\doubao-mouse-bridge-v0.2.0-rc.1-source.zip -Algorithm SHA256`，与该文件内容比较。

## 升级与回退

先从旧窗口或托盘退出，再启动新版。0.1.0 不支持 `--stop`，必须从旧窗口退出。重复启动不会自动替换旧进程。

新版放在独立目录并保留旧目录，需要回退时退出新版，再从旧入口启动。程序不修改登录启动项，已有快捷方式也不会自动更新。检查其目标和参数，避免下次登录又启动旧版；本版尚未完成真实登录验证。

退出或出现语音错误后，检查豆包界面和系统麦克风提示，必要时在豆包手动结束录音。适配进程退出不保证豆包麦克风已关闭。

## 验证依据

- 74 项离线测试通过，覆盖快捷键、长按兜底、后侧键解析、Win/Alt 菜单抑制、托盘生命周期和故障恢复。离线测试不录音、不安装全局输入监听。
- 真实 Tk/pystray 隔离桌面检查通过，覆盖打开窗口、关闭隐藏、暂停恢复、重新检查、设置入口派发和退出。语音及输入监听为替身。
- 此前真实键盘监听与模拟输入的隔离回放已复现旧版菜单抢焦点，并在修复版同组回放中确认前台保持。语音接口使用替身，不能代替实体鼠标与麦克风验收。
- 实际通知区域已显示新版图标。源码包按公开文件清单构建，解压后核对文件集合、语法、链接、常见隐私模式和源码指纹。

GitHub 自动检查结果以关联 PR 的 Checks 页面为准。已查到历史运行因账号计费限制未启动，不能算远端测试通过；本地测试通过不替代远端结果。历史版本的实体语音成功不替代本版终验；完整记录见 [托盘验证记录](../tray-verification.md)。

## 已知限制与隐私

- 本版未完成实体长按、免按、换键及普通键鼠非干扰的完整终验。Windows 11、其他设备、睡眠唤醒、Explorer 重启、高 DPI 与长期常驻未验收。
- 罗技列表是历史设备，不证明在线状态。豆包设置页未实测跳转；罗技按钮只承诺打开软件主窗。
- 豆包接口并非公开稳定接口，升级可能停用。会话归属只有本地标记，运行期间避免混用其他语音入口；异常退出不保证录音停止。
- 菜单屏蔽的极端部分发送失败可能留下未成对释放的无功能屏蔽键，原 Win/Alt 释放仍透传。父子进程轮转日志尚无跨进程协调保证。
- 源码包不含日志、用户设置、罗技数据库、音频、截图、豆包 DLL 或运行环境。本程序没有自己的网络请求和识别服务，豆包可能联网识别。
