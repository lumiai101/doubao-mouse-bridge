# v0.2.0-rc.5 · 版本目录跟随运行中服务

2026-11-10 · 预发布（prerelease）。本版不发布安装器，不自动修改登录启动项，不宣称稳定版。

## 本版解决的问题

豆包输入法会在后台下载新版并预置到 versions 目录。旧逻辑按版本号最大挑选目录，于是会连上尚未生效的新版本；该版本的 rpc.dll 不在已验证名单里，程序因此拒绝启用，界面提示「原生接口版本已变化」。一键恢复用同一规则再选一次，所以反复恢复仍然失败——这不是操作问题，是选目录的缺陷。

## 改动

1. 新增 running_ime_service()：用 Toolhelp32 遍历进程，找到正在运行的 ImeService.exe 并取其所在目录。
2. find_install() 优先返回该目录，条件是该目录的父目录等于 versions 且目录内有 rpc.dll；条件不成立、查询异常或找不到进程时，回退到原来的最大版本选择，行为与旧版一致。
3. 快照与进程句柄都在 finally 中关闭；所有异常被捕获并写调试日志，不向上抛出。
4. ALLOWED_RPC_SHA256 白名单未改动，未纳入任何新哈希。
5. 同版合并 rc.4-local.1 与 rc.4-local.2 的改动：连接双态判定、健康证据 5 秒有效期、事件过滤器区分本程序会话与其他入口、一键恢复真实清理会话、Per-Monitor DPI 与界面刷新节流、schemaVersion 12 与 16 兼容。

## 安装与校验

1. 下载 doubao-mouse-bridge-v0.2.0-rc.5-source.zip，解压到固定目录。
2. 运行 Get-FileHash .\doubao-mouse-bridge-v0.2.0-rc.5-source.zip -Algorithm SHA256，与同目录的 .sha256 文件比对。
3. 运行 start.cmd 启动，程序常驻托盘，不显示主窗口。
