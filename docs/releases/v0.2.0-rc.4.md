# v0.2.0-rc.4 · 启动确认与防漏键源码预览版

在 rc.3 基础上增加语音启动状态限时确认与故障锁存防漏键保护。启动链后最多约 3 秒确认录音状态 3，未进入则取消并锁存停用，不自动重发；故障锁存期间继续屏蔽已匹配的模拟语音组合，避免输入框漏入 `]` 等多余字符，不影响实体键盘与未匹配组合透传边界。保留旧 rc.1/rc.2/rc.3 说明与标签附件，不覆盖。

这是需要安装依赖的源码预览版，需要 uv / Python 依赖环境，不包含 EXE、安装器或独立运行包。实体鼠标语音、真实睡眠唤醒及长期常驻仍未完成完整终验。

## 相比已发布 rc.3

- **启动状态限时确认**：语音启动链后最多约 3 秒核验进入录音状态 3；超时或失败明确取消并锁存停用，防止底层未启动却误报成功，且不自动重发。
- **故障锁存防漏键**：语音故障锁存期间，若处于豆包输入法前台且监听正常，继续吞掉匹配的模拟快捷键，防止鼠标侧键发送的 `Win+]` 残留 `]` 字符漏入输入框；实体键盘、非豆包前台、未匹配组合及暂停状态严格保持透传。
- **回归与隔离验证**：完整本地回归从 83 项增至 96 项（增加 6 项启动确认测试与 7 项吞键保护测试），已全部通过；真实 Tk/pystray 隔离探针 9 项断言全部为 True。
- **自检状态说明**：`scripts/doctor.py` 退出码 0，汇总为 6 pass / 1 warn / 0 fail / 1 skip（warn 为侧键历史设备映射差异，Startup 默认 skip）。警告不代表所有历史设备都已实测或绑定正确。
- **公开文件清单**：公开文件清单为 34 项，已通过语法、文档链接、常见隐私模式与源码指纹检查。构建脚本仅打包清单文件，不收录 `.venv`、日志、配置或第三方二进制。
- **维持本地验收**：维持不使用 GitHub CI 自动触发的决定，不要求远端绿灯，以本地真实与隔离验证为交付依据。

## 下载、运行与自检

1. 下载 `doubao-mouse-bridge-v0.2.0-rc.4-source.zip`，解压到固定目录。
2. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，确认豆包输入法与 Logi Options+ 可用。
3. 双击 `setup.cmd` 安装 Python 3.13 及固定依赖（需要联网）。
4. 双击 `start.cmd`。升级时必须先退出旧版本实例，重复启动不会自动更新或替换正在运行的旧实例。
5. 在源码目录运行只读健康自检：

```powershell
.venv\Scripts\python.exe -X utf8 -B -I scripts\doctor.py
.venv\Scripts\python.exe -X utf8 -B -I scripts\doctor.py --quick
```

需要交互式 Windows 桌面。测试会短暂显示独立窗口，不录音、不安装全局输入监听。自检通过不替代实体语音与睡眠唤醒验证。

## 实体反馈与限制边界

- **人工恢复反馈**：用户在实体问询中反馈语音出字结束、无菜单抢焦点或多余字符、123/退格/左右键/滚轮全部正常；但这属于当前运行实例的人工恢复反馈（现用进程未重启），未确认加载磁盘最新 rc.4 补丁，不能将其当作 rc.4 磁盘源码的最终验收。
- **睡眠问题与版本定性**：真实睡眠后底层失效并未根治，手动重启恢复反馈不代表根因修复。稳定版仍不放行，本次维护者明确接受限制，仅作为 prerelease 预览发布。
- **免按与长时运行**：免按模式、运行中换键、再次真实睡眠唤醒、长期常驻等场景仍未完整验证。
- **安全人工恢复操作**：若需手工重启豆包，必须先保存当前编辑文字、确认麦克风录音已结束、通过托盘正常退出并重新打开；严禁强杀输入法服务，本程序亦不自动修改系统设置或启动项。
- **升级与回退**：升级时新启动程序不会强杀或替换旧实例；若需回退，退出新程序并重新启动保留的旧版本目录即可。
