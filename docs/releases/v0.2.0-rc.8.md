# v0.2.0-rc.8 · 每用户 Windows 安装程序（预发布）

2026-11-18 · 预发布（prerelease）。本版在 [rc.7](v0.2.0-rc.7.md) 源码归档预发布的基础上，合入窗口、任务栏与 EXE 图标统一（FLOW-141）与第三方许可及源包对应补项（FLOW-195），把每用户、免管理员的 Inno Setup 安装器完整发出来。

> 状态：**安装器已构建并通过本机预构建与静态契约校验，尚未公开发布二进制**。发布前还需两席独立评审，然后打 `v0.2.0-rc.8` tag 并建 Release。

## 本版改了什么

1. **每用户安装器**（随 rc.7 落地，本版首次公开二进制）：`PrivilegesRequired=lowest`，默认装到 `%LOCALAPPDATA%\Programs\DoubaoMouseBridge`，不写 HKLM、不注册服务；安装任务可选桌面快捷方式（无参数）与登录自启（`--background`，只驻留托盘）；卸载由 `unins000.exe` 完成。
2. **版本号单一来源**：`packaging/windows-installer.iss` 用 `#ifndef AppVersion` / `#error AppVersion is required` 强制命令行传入，不再有静态兜底值；缺 `/DAppVersion` 时 ISCC 预处理直接中止。
3. **窗口、任务栏与 EXE 图标统一**（FLOW-141）：`create_app_icon_image()`、`apply_window_icon()`、`write_app_icon()` 让标题栏、任务栏按钮与 EXE 内嵌图标（16/32/48/256 像素）都来自同一份托盘图形；`scripts/build_windows.py` 打包前调用 `bridge.write_app_icon(icon)`，不再另拼尺寸表。
4. **第三方许可与 LGPL 源包**（FLOW-195）：`scripts/collect_licenses.py` 按 PyPI 记录的 SHA-256 校验 pynput 与 pystray 源包（pystray 0.19.5 只有 wheel，按纯 Python 源码本体处理）；Tcl 与 Tk 正文逐份落盘为 `tcl-tk/tcl-license.terms` 与 `tcl-tk/tk-license.terms`；Tcl 正文随仓固定在 `packaging/licenses/Tcl-8.6.txt`，缺失即硬失败；GPLv3 与 Apache-2.0 正文缺失同样硬失败。
5. **版本与清单**：`scripts/build_release.py` 与 `scripts/build_windows.py` 的默认版本改为 `0.2.0-rc.8`；`scripts/check_release.py` 的 `FILES` 加入本文件，公开文件数 57 增至 **58**。

- `python -B -I scripts/build_release.py`：源码包通过打包前与解压后复检，58 条目完整，退出码 0。
- 安装器预构建（宿主机 `.venv` 的 PyInstaller 6.22.3 + 官方签名 Inno Setup 7.1.0）：
  - `scripts/collect_licenses.py` 收齐全部许可，`tcl_tk_missing` 为空；
  - `scripts/build_windows.py --version 0.2.0-rc.8` 产出 `DoubaoMouseBridge-0.2.0-rc.8-Setup.exe`；
  - 主程序 EXE 为 PE subsystem 2（不带控制台窗口）；
  - 主程序与安装器 EXE 的 16/32/48/256 像素内嵌图标与托盘图形不透明像素差异均为 0。

## 未完成与限制

- 未做代码签名，Windows SmartScreen 或安全软件可能提示未知发布者。
- 实体语音出字、侧键触发、登录自启后的托盘驻留、睡眠唤醒与长期常驻属真人现场验收，本版未代跑。
- 本机沙箱禁止写桌面、开始菜单与 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall`，因此完整静默安装/卸载在受限环境里只能跑到解压阶段并按回滚退出；安装器本身的契约由 `tests/test_installer_contract.py` 的静态断言守住，完整实装见 [rc.7 说明](v0.2.0-rc.7.md) 与 [Windows 安装版](../windows-installer.md)。
- `src/doubao_mouse_bridge.py` 目前只接受 `--config`、`--background`、`--stop`；`docs/windows-installer.md` 提到的 `--verify-package` 参数尚未实现，本版不改 `src/`。
