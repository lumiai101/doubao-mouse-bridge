# v0.2.0-rc.6 · 豆包 v1.1.1.5 兼容与一键安装程序

2026-11-15 · 预发布（prerelease）。本版首次附带一键安装程序，仍不修改登录启动项，不宣称稳定版。

## 本版解决的问题

豆包输入法自动升级到 v1.1.1.5 后，配置格式变为 schemaVersion 19，而程序只放行 schemaVersion 12 与 16，且 `rpc.dll` 的 SHA-256 不在白名单里。表现是：豆包在后台升级后，重启电脑再打开程序就一直显示“断开”，鼠标侧键不再触发语音。这不是操作问题，是版本白名单落后于豆包本身。

## 改动

1. 白名单补入豆包 v1.1.1.5、v1.1.1.3、v1.0.0.23 的 `rpc.dll` SHA-256，配置格式放行 schemaVersion 19；未知版本仍然拒绝启用，不静默降级。
2. 语音会话释放与命令下发不再对空句柄调用：`_release()` 在 join 超时后也清空会话状态，`_command()` 在进程或连接缺失时直接返回 False，避免 `'NoneType' object has no attribute 'send'`。
3. 一键恢复遇到残留进程与空连接的破损会话时，先安全释放再重建可探测会话，探针返回 0 时不误判为不确定状态。
4. 新增一键安装程序：`DoubaoMouseBridge-v0.2.0-rc.6-installer.zip`。它校验安装包与 EXE 的 SHA-256、关闭正在运行的旧实例、把旧安装备份为 `DoubaoMouseBridge.backup-<时间戳>`、安装到 `%LOCALAPPDATA%\Programs\DoubaoMouseBridge`，然后启动并显示进程 PID。
5. 发布清单同步纳入安装程序相关文件（`packaging/installer/`、`scripts/build_installer.ps1`、`requirements-build.txt`），并移除仓库根目录误提交的截图文件。

## 安装与校验

一键安装程序：

1. 下载 `DoubaoMouseBridge-v0.2.0-rc.6-installer.zip`，整个压缩包解压到一个文件夹。
2. 双击 `install.cmd`，等待出现 `Install OK` 与运行中的 PID。
3. 校验：与同目录的 `.sha256` 文件比对安装包摘要；脚本自身也会校验包内 EXE 的 SHA-256。

源码包：

1. 下载 `doubao-mouse-bridge-v0.2.0-rc.6-source.zip`，解压到固定目录。
2. 运行 `Get-FileHash .\doubao-mouse-bridge-v0.2.0-rc.6-source.zip -Algorithm SHA256`，与同目录的 `.sha256` 文件比对。
3. 运行 `setup.cmd` 再运行 `start.cmd`，程序常驻托盘。
