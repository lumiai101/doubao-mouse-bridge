# v0.2.0-rc.2 · 托盘源码预览版

这是 v0.2.0-rc.1 的修正版源码预览。它补上两条会影响实际触发的边界：等待长按期间切换前台窗口并松键时不再误启动；上一次识别处理较慢时，下一次触发会先检查并回收已空闲的旧语音子进程，仍忙则明确停用并提示，而不是静默丢掉触发。

**本版仍未完成实体鼠标语音、真实登录和长期常驻验收。** 这是需要安装依赖的源码预览版，不包含 EXE、安装器或 Python 运行环境。

## 本版变化

- 保留 v0.2.0-rc.1 的 Windows 托盘、后侧键只读检查、Win/Alt 菜单抑制和深蓝鼠标声波图标。
- 在模拟长按尚未达到启动等待时间时核对当前前台窗口；窗口变化会清除等待状态，双用途长按/免按组合在切窗后松键也不会启动豆包语音。
- 识别处理超过约 15 秒后，下一次触发先查询豆包状态；若已空闲则回收旧子进程后继续，若仍忙则显示故障并停止新触发，不静默跳过。
- 修正离线测试说明：`tests/test_tray.py` 会短暂创建并显示真实 Tk 窗口，完整测试需要可用的 Windows 桌面会话；不录音、不安装全局输入监听。

## 下载并运行

1. 下载附件 `doubao-mouse-bridge-v0.2.0-rc.2-source.zip`，解压到固定目录。
2. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，确认豆包输入法和 Logi Options+ 本身可以正常使用。
3. 双击 `setup.cmd`，安装 Python 3.13 与固定版本依赖。需要联网。
4. 双击 `start.cmd`，在右下角通知区域打开“鼠标＋声波”，核对双方快捷键，再在普通文本框中实测。

推荐 Windows x64、Python 3.13，含 tkinter。依赖为 pynput 1.8.2、six 1.17.0、pystray 0.19.5、Pillow 11.3.0。

附件 `.sha256` 是源码 ZIP 的校验值。可在 PowerShell 中运行：

```powershell
Get-FileHash .\doubao-mouse-bridge-v0.2.0-rc.2-source.zip -Algorithm SHA256
```

## 升级与回退

先从旧窗口或托盘退出，再启动新版。新版放在独立目录并保留旧目录，需要回退时退出新版，再从旧入口启动。程序不修改登录启动项，已有快捷方式也不会自动更新；本版尚未完成真实登录验证。

退出或出现语音错误后，检查豆包界面和系统麦克风提示，必要时在豆包手动结束录音。适配进程退出不保证豆包麦克风已关闭。

## 已知限制与隐私

- 本版未完成实体长按、免按、换键及普通键鼠非干扰的完整终验。Windows 11、其他设备、睡眠唤醒、Explorer 重启、高 DPI 与长期常驻未验收。
- 罗技列表是历史设备，不证明在线状态。豆包设置页未实测跳转；罗技按钮只承诺打开软件主窗。
- 豆包接口并非公开稳定接口，升级可能停用。会话归属只有本地标记，运行期间避免混用其他语音入口；异常退出不保证录音停止。
- 菜单屏蔽的极端部分发送失败可能留下未成对释放的无功能屏蔽键。父子进程轮转日志尚无跨进程协调保证。
- 源码包不含日志、用户设置、罗技数据库、音频、截图、豆包 DLL 或运行环境。本程序没有自己的网络请求和识别服务，豆包可能联网识别。
