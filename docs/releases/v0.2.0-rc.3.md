# v0.2.0-rc.3 · 自动自检源码预览版

在 rc.2 的语音触发修复基础上，发布一键只读自检与本地验收流程。应用运行源码未改，主要增加验证工具、回归测试和交付说明。旧 rc.2 标签与下载附件保留，不覆盖。

这是需要安装依赖的源码预览版，不包含 EXE、安装器或 Python 运行环境。实体鼠标语音及长期常驻尚未完整终验；用户反馈目前登录启动稳定，本轮不再安排注销/重启实测，不将其写成自动验证通过。

## 相比已发布 rc.2

- 增加 `scripts/doctor.py`，串联本地回归、真实 Tk/pystray 隔离探针、侧键只读检查、发布门禁、进程路径、最近 200 行日志及豆包安装 RPC 哈希白名单检查。不新增依赖、不录音、不注入按键、不修改用户设置或重启程序。
- Startup 默认跳过；只有显式添加 `--check-startup` 才只读核对快捷方式，仍不执行真实登录验证。`--quick` 另跳过回归测试和隔离托盘探针。
- 修复自检的侧键中文状态误判、成功查询但无运行进程时误报警告，以及单项异常导致报告中断。新增 5 项回归测试，完整本地回归为 83 项。
- 按维护者选择不使用 GitHub CI，取消 push / pull_request 自动触发，仅保留手动入口；以本地验证作为交付依据，不要求充值或等待远端绿灯。
- 公开文件清单为 33 项，包含本版说明。构建脚本只打包清单内容，检查打包前、ZIP 文件集合、完整性及解压后目录；不收录 `.venv`、日志、配置、音频、截图或豆包 DLL。

## 下载、运行与自检

1. 下载 `doubao-mouse-bridge-v0.2.0-rc.3-source.zip`，解压到固定目录。
2. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，确认豆包输入法与 Logi Options+ 本身可用。
3. 双击 `setup.cmd`，安装 Python 3.13 及固定依赖，此步需要联网。
4. 双击 `start.cmd`；从通知区域打开“鼠标＋声波”，核对两边快捷键。升级时先退出旧实例，重复启动不会替换旧实例。
5. 在源码目录运行只读自检：

```powershell
.venv\Scripts\python.exe -X utf8 -B -I scripts\doctor.py
.venv\Scripts\python.exe -X utf8 -B -I scripts\doctor.py --quick
```

需要交互式 Windows 桌面。完整测试会短暂显示真实 Tk 窗口，但语音与输入监听使用替身，不开启麦克风。

退出码 `0` 允许存在警告，`1` 表示失败，请查看汇总。本机完整自检为 **6 通过、1 警告、0 失败、1 跳过**；快速模式为 **4 通过、1 警告、0 失败、3 跳过**。唯一警告为侧键绑定需检查，登录启动项按约定跳过。警告不代表用户已接受不匹配或实体侧键已验收。

## 边界与回退

- 隔离托盘通过不证明当前常驻实例图标仍可见；安装哈希通过不证明 RPC 在线；日志检查不证明程序长期健康。
- 实体长按、免按、换键、普通键鼠非干扰、睡眠唤醒、Explorer 重启、高 DPI、Windows 11 和长期常驻未完成本版完整验收。缺少可核验报告的跨会话真实语音结果不计为通过。
- 保留 rc.2 的切窗取消、慢识别恢复及 Win/Alt 菜单抑制修复，也保留接口非公开、会话归属不可靠、异常退出不保证豆包停止录音、极端部分发送失败与跨进程日志轮转等限制。
- 不更新现用部署或登录启动项，不自动合并主分支。需要回退时退出新版，从保留的旧目录启动；出现语音异常先检查豆包和系统麦克风提示，必要时手动结束录音。
- 豆包可能联网识别，本程序没有自己的识别服务。公开包不含用户配置、音频和原始日志。
