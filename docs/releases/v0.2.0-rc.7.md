# v0.2.0-rc.7 · 真正的 Windows 安装程序（源码归档预发布）

2026-11-17 · 预发布（prerelease）。本版把 rc.6 的「解压 + 批处理安装」换成每个用户、免管理员的 Inno Setup 安装器，并补齐桌面/开始菜单快捷方式、登录自启与卸载。

> 状态：**源码归档预发布已公开**（tag `v0.2.0-rc.7`，指向 `2abde7f`）。本次 Release 只含源码归档、变更说明与 SHA-256 清单，未公开安装器二进制；完整安装器随 [rc.8](v0.2.0-rc.8.md) 补发。

## 本版改了什么

1. 新增 `packaging/windows-installer.iss`：`PrivilegesRequired=lowest`，装到当前用户的 `Programs/DoubaoMouseBridge`，不写 HKLM、不注册服务。
2. 新增 `scripts/build_windows.py`：先用 PyInstaller 打出无控制台单目录应用，再用 Inno Setup 编译安装器；编译安装器前必须提供含第三方许可与 LGPL 源包的 `--licenses` 目录，否则拒绝出包。
3. 安装任务可选桌面快捷方式与登录自启；自启快捷方式带 `--background`，登录后只驻留托盘。
4. 卸载由安装器自带的 `unins000.exe` 完成，只移除本安装器拥有的文件与快捷方式。
5. 安装器版本号改为命令行传入，不再写死在脚本里。

## 验证

- 离线回归全绿（命令与用例数见发布提交的交付说明）。
- `scripts/check_release.py` 通过：公开文件清单已纳入安装器相关文件。
- 隔离实装（装到临时目录、独立 AppId 与 AppMutex，不触碰正式卸载登记）：
  - 静默安装成功，落盘 `DoubaoMouseBridge.exe`、`_internal/`、`licenses/`、`unins000.exe`；
  - 桌面快捷方式指向安装目录的 EXE，无参数；
  - 启动文件夹快捷方式指向同一 EXE，参数为 `--background`；
  - 开始菜单程序组已创建；
  - 卸载后安装目录、三个快捷方式与开始菜单组全部移除，正式安装的卸载登记未被改动。
- 打包出的 EXE 为 Windows GUI 子系统（PE subsystem 2），不带控制台窗口。
